# TCS NQT DSA Prep

Java solutions for problems commonly asked in the **TCS NQT** exam, organized topic-wise for structured, recruiter-friendly practice.

## 📂 Topics Covered

### Array (7)
- Buy and Sell Stocks
- Kadane's Algorithm
- Reverse Array
- Rotate Array by K Elements
- Second Largest Element
- Third Maximum Number
- Trapping Rainwater

### Number Theory (4)
- Factorial
- Fibonacci Series
- GCD & LCM Calculator
- Prime Check

### Strings (3)
- Check Anagram
- Palindrome Check
- Reverse String

## 🚀 How to Run

```bash
javac FileName.java
java FileName
```

Each file is self-contained — compile and run it directly.
